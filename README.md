# 🌱 Sprout（青禾记账）

个人轻量记账工具（Windows + Android）。简洁、高效、本地存储、无需联网。

## 功能

- ✏️ **记一笔** — 金额 + 分类 + 日期 + 备注
- 📅 **明细** — 日历视图 + 按日清单 + 编辑/删除
- 💰 **预算** — 总预算 + 分类预算 + 预算执行
- 📊 **统计** — 周/月/年 + 饼图 + 趋势柱状图 + 折叠列表
- 👤 **我的** — 语言切换 / 深色模式 / 导出导入 / 分类管理

## 技术

Tauri 2 + React 19 + TypeScript + Ant Design 6 + SQLite

## 启动

```bash
npm install
npm run tauri dev
```

## 测试

```bash
npm test
```
